# KBIDO Website — 2027 refresh

This package contains the bilingual English/Tigrinya KBIDO website.

## Files
- `index.html` — complete responsive website
- `assets/kbido-symbol.jpg` — KBIDO emblem used in the navigation and browser tab\n- `assets/kbido-logo.jpg` — full official logo displayed in the footer\n- `fonts/` — locally hosted Latin and Ethiopic fonts

## Preview locally
Open `index.html` in a modern browser. Keep the `fonts` folder beside it.

## Publish with GitHub Pages
1. Back up the current repository.
2. Upload/replace `index.html` and upload the complete `fonts/` and `assets/` folders in the repository root.
3. Commit the changes.
4. In repository Settings → Pages, confirm the existing publishing source.
5. Open the GitHub Pages URL and test the English/Tigrinya switch on desktop and mobile.

## Important publication checks
- The Tigrinya text is a carefully prepared draft, not a certified translation. Have a fluent Tigrinya editor familiar with church and development terminology review it before public release.
- Confirm the organization's official registered English and Tigrinya names and its exact institutional affiliation against registration documents.
- Confirm that the establishment year, staffing and volunteer figures, telephone number and geographic reach remain current and are approved for public release.
- The website intentionally does not invent board-member names, registration numbers, donor lists, project achievements, office street address, social-media accounts or donation/payment details.
- The requested `kbido.com` domain is not configured here. Connect it only after domain registration and DNS setup have been completed.
